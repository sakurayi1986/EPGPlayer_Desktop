EPGPlayer For Desktop is licensed under the GNU General Public License v3.0 or later
(see [LICENSE](LICENSE)). The released binaries contain the third-party software
listed below. Because FFmpeg and mpv are built in their GPL configuration, the
binaries as a whole are distributed under the GPL v3.

## Inspiration

The feature set follows [imxieyi/EPGPlayer](https://github.com/imxieyi/EPGPlayer)
(iOS / iPadOS / macOS, MPL-2.0). This project is an independent reimplementation
in Rust; no source code from EPGPlayer is included. It is not affiliated with or
endorsed by the EPGPlayer author.

## Linux build (statically linked)

Built by [`scripts/build-static.sh`](scripts/build-static.sh) /
[`scripts/static/build-deps.sh`](scripts/static/build-deps.sh), which pin the versions below.
The exact sources used for a release are published alongside it as
`EPGPlayer_Desktop-third-party-sources.tar.gz` ([`scripts/pack-sources.sh`](scripts/pack-sources.sh)).
License texts are included in the release archive under `licenses/`.

## Windows build

`libmpv-2.dll` is redistributed unmodified from
[shinchiro/mpv-winbuild-cmake](https://github.com/shinchiro/mpv-winbuild-cmake),
release `20261004` (`mpv-dev-x86_64-20261004-git-413ff0b1cd.7z`,
SHA-256 `445fc72a8aa10980504355a5d99c9a0a128c2fa177e029996fb312d9d3193d45`).
It contains mpv (`v0.41.0-1095-g413ff0b1c`), FFmpeg (GPL build, including libaribcaption)
and the other libraries listed in that project's
[`packages/`](https://github.com/shinchiro/mpv-winbuild-cmake/tree/master/packages) directory,
which also records the source location and version of each one. It is licensed under the GPL v3.

## Rust crates

About 340 crates (Linux) / 250 crates (Windows), mostly under MIT and/or Apache-2.0;
others use BSD, ISC, Zlib, Unicode-3.0, BSL-1.0, MPL-2.0, CDLA-Permissive-2.0 and
LGPL-2.1 (libmpv2). egui embeds fonts under the SIL Open Font License 1.1 and the
Ubuntu Font License 1.0. The full license text of every crate is in
`THIRD_PARTY_LICENSES.txt` in each release archive, generated by
[`scripts/gen-third-party.py`](scripts/gen-third-party.py).
